# 片刻 · 私人影音库

一个无需后端的私人视频收藏应用，支持 B站、YouTube、影视剧播放页等 HTTP(S) 链接。

## 使用

1. 打开 `index.html` 即可在浏览器体验。正式使用建议将本文件夹三个文件上传到 GitHub 仓库根目录，开启 GitHub Pages。
2. 点击「收藏视频」，粘贴视频地址，填写标题，保存。
3. 在「想看 / 正在看 / 已看完」间管理片单；点击「去观看」在原平台播放。
4. 点击「备份」导出 JSON；「导入」合并备份（按视频链接去重）。
5. 在 iPhone Safari 打开 GitHub Pages 地址，点分享 → 添加到主屏幕。

## 注意

- 所有记录仅存储在当前浏览器的 localStorage；清除网站数据或换设备可能导致记录丢失，请定期备份。
- YouTube 的标准链接可自动显示封面，其他平台可手动填写图片地址。标题、时长、观看进度通常无法跨平台自动读取。
- 影视链接必须指向合法播放页面；软件不下载、破解或托管影视内容。
- 离线访问和跨设备同步尚未实现；网络访问视频仍需原平台可用。
